# Project map

- app/: App Router pages, layout, metadata routes and global CSS.
- app/services/[slug]/: six build-time-generated service detail pages.
- components/: navigation, hero media, comparison, packages, gallery, form and shared sections.
- data/: central business and content files.
- lib/: validation, navigation gestures and SEO helpers.
- public/images/: generated local WebP assets and social image.
- public/: favicon, Apple icon, app icons and web manifest.
- scripts/: portable development entry point and export integrity checker.
- tests/: meaningful booking and swipe-behavior unit tests.
- out/: generated deployable static files (created by npm run build).

ZIP layout: VELORA-Auto-Studio/source/ contains the project; VELORA-Auto-Studio/out/ is the ready-to-upload export. A new source build produces source/out/.
