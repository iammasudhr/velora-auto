# Launch checklist

- Replace demo brand/location, confirm contact number, working hours, service offerings and prices.
- Replace sample testimonials with consented, verified client reviews or remove the section.
- Retain illustration labelling unless real, permissioned project photographs replace it.
- Review legal copy for the actual operator and WhatsApp data-handling process.
- Set actual origin and enable live indexing; rebuild.
- Confirm calls, WhatsApp URL and manual booking reply workflow.
- Test phone letters/punctuation, 9/10/11 digits, missing consent, invalid date and past time.
- Test real iPhone/Android: dock taps, left/right swipes on dock, scroll down/up, keyboard, notches, portrait/landscape and reduced motion.
- Verify HTTPS, static routing, missing-page handling, page metadata and OG image.
- No backend, form-service account or payment setup is required for WhatsApp enquiries.
